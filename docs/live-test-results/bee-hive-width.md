## Why, per grain

`items_per_second = ITEMS_PER_CELL / cell_wall_seconds`, computed from **clean batches only** — gate 1 (`retry-contaminated`) drops any batch whose calls carried a transport retry, because a 20 s backoff timed inside the call it retries is the instrument, not the result. Both readings are published below.

`direction_required(3) = 3`: a width separates only by beating the control on **all three** paired repetitions.

## Validity and cost

- **48 cells dialled**, 1 carrying a gate.
- **2205 s** of measured wall clock across the rung.
- **1,423,440 prompt tokens, 102,336 completion tokens.**
- Acceptance was perfect in every cell: zero refusals, zero truncations, zero abandoned calls. Every width-8 retry eventually succeeded, so the instability cost wall clock and never data.
